# 🤖 Nova – Discord AI Chatbot

Nova is a **Discord chatbot** powered by the [Groq API](https://groq.com/) and large language models.  
It listens for mentions in your server and responds intelligently, making conversations more interactive and fun.

---

## ✨ Features
- 🟢 Connects seamlessly to Discord using `discord.py`
- 💬 Responds only when mentioned (`@Nova`) to avoid spam
- ⚡ Uses **Groq’s LLM API** (`openai/gpt-oss-120b`) for smart replies
- 🔒 Secure API key handling via environment variables
- 🛠️ Lightweight, minimal codebase – easy to extend
- 📜 Message length capped to avoid Discord limits (2000 characters)
